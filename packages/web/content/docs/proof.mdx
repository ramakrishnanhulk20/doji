Doji asks you to take nothing on trust. Each answer below points to a screen on this site, a file in the open source repository, and a transaction on Mezo's testnet explorer where one exists.

## Does it really run on Mezo?

veBTC is the collateral and MUSD is the loan. Doji calls veBTC, PoolsVoter, ValidatorsVoter, the veBTC fee distributor, MUSD, MUSD's PriceFeed and the BTC token, and does nothing without them.

## Is it a real market, and who pays?

A two-sided market that extends what MUSD can do: veBTC holders borrow without ending their lock, and MUSD holders lend at a fixed rate to a fixed date. The protocol earns 10% of the interest and a 5% penalty on failed loans.

## Is my Bitcoin safe in it?

Two immutable contracts, a written rulebook with 29 rules each pointing to the code that keeps it, fuzz and invariant tests, fork tests against Mezo mainnet, an independent review with every finding fixed, and one command that proves the main promise live.

## Can I use it without help?

A first-time user can borrow and lend without help: live numbers before a wallet, Mezo testnet added by the wallet button, a faucet link when test BTC runs low, lock and borrow in one action, dates as calendar days, the exact amount owed before signing, and errors in plain words.

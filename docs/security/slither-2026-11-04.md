## What the `lib` filter also left out

The `lib` pattern matches the dependencies in `lib/` (OpenZeppelin and forge-std) and also Doji's own `src/libraries/` (PassThrough and LockReader), and it drops every result that touches either. A run that leaves out only the dependencies keeps Doji's libraries:

```bash
slither . --exclude-dependencies
```

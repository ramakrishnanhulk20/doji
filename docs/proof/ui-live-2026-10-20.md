# Live website test on Mezo testnet, 2026-10-20 and 2026-10-21

The Doji website was driven in a headless Chrome against Mezo testnet with a test wallet, clicking through the real pages: Borrow, My loans and Lend. Every transaction below was sent from the page itself, then checked on chain through both the RPC and Mezo's explorer. Contracts: LoanManager 0x983F2cD6e30492962104fc4dde8dbb5bd9d05Cfa, CreditMarkets 0x62cBa75f2fAA834ddCa4bF012258368D17Bbb2de (code at commit 09e20c3). Test wallet 0x92DcCb70C33300848Da555eDe8597d3F7037AE2b.

The loan cost 0.01295 MUSD of interest. The 0.0005 BTC stays locked in veBTC #392 until Thursday 29 October, as veBTC locks do.

What this run found: some of the load-balanced nodes behind Mezo's public RPC did not see a mined transaction for up to 494 seconds, while the explorer had it at once. The page waited 12 seconds, then called the successful offer "Failed" and offered to send it again. The fix (commit f05f64b) confirms every transaction from the RPC and the explorer together for up to ten minutes, treats only a revert as a failure, and never offers a step again once it has a transaction hash.

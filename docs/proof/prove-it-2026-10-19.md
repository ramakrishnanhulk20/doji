# Prove-it run on Mezo testnet, 2026-10-19

One command, `bash packages/contracts/script/prove-it.sh`, run against the live Doji contracts on Mezo testnet (code at commit 1a9bee7, deployed at abef0b1). It locks a little test Bitcoin, borrows MUSD at a fixed rate, checks the result on chain, tries three attacks as a stranger, repays and takes the position back.

The chain then reads `ownerOf(411)` on veBTC as the Wave 2 LoanManager, `positionOf(411)` names PayDown as the reward operator, each pool holds 3,604,106,866,949,489 of #411's vote weight, and both incentive contracts show the amounts above for the epoch that started on Thu 29 Oct (`tokenRewardsPerEpoch` 20e18 MUSD and 3e14 BTC). What this does not prove yet: the pay-down itself. Incentives can be claimed only after their epoch ends. The harvest that claims them, repays MUSD and sells BTC above the oracle floor is the next section of this page, added once it has run.

## How to check it yourself

```bash
cast call 0xB63fcCd03521Cf21907627bd7fA465C129479231 "ownerOf(uint256)(address)" 411 --rpc-url https://rpc.test.mezo.org
cast call 0x89Dc7C4a7Cbfddf3Cb7a00b5f3fEFaB47aC61a1f "isInVault(uint256)(bool)" 2 --rpc-url https://rpc.test.mezo.org
cd packages/contracts && bash script/verify-testnet.sh deployments/31611-wave2.json
```

The setup script is `packages/contracts/script/wave2-live.sh`. It records every transaction it sends, so running it again after a failure never sends anything twice.
